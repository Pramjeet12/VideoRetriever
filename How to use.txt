VideoRetriever - How to Use

1. Go to the project folder
cd VideoRetriever

2. Make sure Docker Desktop is running

3. Keep your .env file in the project root

4. Run with Docker Compose
docker compose up --build

5. Open in browser
http://localhost:5000

6. Stop the container
docker compose down

Direct Docker run:

1. Build image
docker build -t videoretriever .

2. Run container
docker run --env-file .env -p 5000:5000 videoretriever

3. Open in browser
http://localhost:5000
